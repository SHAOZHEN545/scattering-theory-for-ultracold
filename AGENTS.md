# Markdown math formatting

Use $...$ for inline math and $$...$$ for display math in Markdown files and Markdown code blocks. Do not use backslash-parenthesis or backslash-bracket math delimiters there.

Preserve Obsidian wikilinks, native callouts, and the shared figure syntax. Prefer existing Obsidian and Quartz capabilities over custom rendering code. Keep notes and attachments inside Scattering theory notes/.
